# commute-form

稼働費入力フォーム（GitHub Pages）＋ Google Apps Script / スプレッドシート。

- `index.html` … 入力フォーム本体。`GAS_URL` にWebアプリのデプロイURLを設定する。
- `apps-script/commute-expense-sheet.gs` … スプレッドシート側のGASコード。

---

## トラブルシューティング

### ❌「DriveApp.getFolderById を呼び出す権限がありません」

`DriveApp` や `UrlFetchApp` を使うコードを後から追加した場合に出ます。
**Webアプリはデプロイした時点で承認済みのスコープでしか動かない**ため、
コードを保存しただけでは新しい権限が反映されません。承認し直して再デプロイが必要です。

1. Apps Script エディタでコード内に `/** @OnlyCurrentDoc */` があれば **削除**する。
   これがあるとスクリプトは「このスプレッドシートのみ」に制限され、
   別フォルダを触る `DriveApp.getFolderById()` は必ず失敗する。
2. 「プロジェクトの設定」→「`appsscript.json` マニフェスト ファイルをエディタで表示する」を ON。
   `appsscript.json` に `"oauthScopes"` の記載があれば **そのブロックごと削除**する。
   明示すると自動検出が無効になり、書き忘れたスコープが永久に付与されない。
   （スコープを手書きで管理すると1つ漏れただけで同じ症状が再発するので、自動検出に任せる）
3. エディタで `exportCommutePdf` を選んで実行、または
   スプレッドシートのメニュー「📋 稼働費管理 →🩺 PDF保存をテスト」を実行し、
   **承認画面で Drive を含む権限を許可**する。
4. 「デプロイを管理」→ 対象デプロイの **鉛筆（編集）** → バージョンを **「新バージョン」** → デプロイ。
   ここを飛ばすと、古いスコープのままのWebアプリが動き続ける。

> 「新しいデプロイ」を作ると **URLが変わる** ので、必ず既存デプロイの「編集」から
> 新バージョンを出すこと。URLを変えた場合は `index.html` の `GAS_URL` も更新する。

### ❌「Failed to fetch」

リクエストがサーバーに届く前にブラウザ側でブロックされている状態。

- デプロイの「アクセスできるユーザー」が **【全員】** になっているか。
  「Googleアカウントを持つ全員」だとログイン画面へリダイレクトされ、
  CORSでブロックされてこのエラーになる。
- `index.html` の `GAS_URL` が、現在のデプロイURL（末尾 `/exec`）と一致しているか。

### ❌「Unexpected token '<' ... is not valid JSON」

GASがJSONではなくHTML（ログイン画面・権限エラー画面）を返している。
`doPost` 内の例外はJSONで返るので、**コードではなくデプロイ設定側**の問題。
上記「Failed to fetch」と同じ箇所を確認する。

### 動作確認

デプロイURL（末尾 `/exec`）をブラウザで直接開くと `doGet` が状態JSONを返す。

| 表示 | 意味 |
|---|---|
| `{"ok":true,"data":{"status":"ready",...}}` | デプロイは正常 |
| `Script function not found: doGet` | 最新コードが未反映（再デプロイが必要） |
| ログイン／アカウント選択画面 | 「アクセスできるユーザー」が全員になっていない |
| 「ファイルが見つかりません」 | URLが古い／デプロイが削除済み |

## 距離の自動計算について

C列（稼働場所）・I列（高速有無）の編集を拾う処理は、**インストール型トリガー**
（`handleEdit`）で動かしている。関数名を `onEdit` にすると単純トリガーとして
実行され、単純トリガーは認可が必要な **Maps サービスを呼べない**ため。

トリガーはメニューの「⚙️ 初期設定」または「🔌 自動計算トリガーを再設定」で登録される。
距離が自動で入らない場合はここを実行する。

同一経路（自宅⇔現場）の距離は `CacheService` に6時間キャッシュしているので、
同じ場所を続けて入力しても Maps API は毎回は呼ばれない。
